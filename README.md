# \# VoidNightfall

# 

# A 3D top-down tower defense / action game built with Unity 6.

# 

# \## Gameplay

# \- Survive waves of enemies

# \- Collect resources: Carbonium, Metal, Energy

# \- Build defenses and upgrade your base

# \- Mix of ranged and melee combat

# 

# \## Built With

# \- Unity 6 (6000.4.1f1)

# \- Universal Render Pipeline (URP)

# \- TextMeshPro

# \- C#

# 

# \## ⚙️ How to Run

# 1\. Clone this repository

# 2\. Open with \*\*Unity 6 (6000.4.x)\*\*

# 3\. Open scene: `Assets/Scenes/SampleScene`

# 4\. Press \*\*Play\*\*

#
